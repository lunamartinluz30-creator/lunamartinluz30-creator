# Hola, soy Alexandra

Construyo sitios web y asistentes de WhatsApp para negocios pequeños: catálogos, reservas, citas y páginas que cargan rápido y se entienden.

Vengo de cinco años atendiendo clientes cara a cara, en dos idiomas, y eso se nota en cómo trabajo: primero entiendo qué necesita la persona, después escribo el código.

## Proyectos propios

- **Alexandra Estudio** — mi estudio de servicios digitales. [alexandra-estudio.com](https://alexandra-estudio.com)
- **Reservas por WhatsApp** — asistente para posadas y hoteles: verifica disponibilidad, calcula el total y aparta la habitación con vencimiento. Atiende varios negocios desde una sola instalación. TypeScript, Node.js, SQLite, 51 pruebas automatizadas.
- **Dashboard de ventas Porsche** — proyecto de formación: panel de ventas por modelo. [Ver repositorio](https://github.com/lunamartinluz30-creator/dashboard_porsche_sale)

## Trabajo para clientes

- **Catálogo PWA** para una empresa de vidrio, aluminio y acero: catálogo instalable en el teléfono. JavaScript.
- **Bot de reservas por WhatsApp** para una posada: atiende consultas y crea la reserva en Google Calendar. JavaScript, Cloudflare Workers.

El código de los clientes es privado. Puedo mostrar cómo funciona en una llamada.
